Project Name: StudentCare - Student Management Website

Description:
StudentCare is a responsive student management website built using HTML, CSS and JavaScript.
It has a public section where visitors can browse student profiles and learn about the platform,
and an admin panel where administrators can manage student records.

How to Run:
1. Download or clone the project folder
2. Open index.html in any web browser (Chrome, Firefox, Edge etc)
3. The website will load with the public view

Admin Login:
- Username: akhil
- Password: akhil@123
- Click "Admin Login" in the navigation bar to open the login form

Features:
- Responsive design (works on desktop, tablet and mobile)
- Public website with hero banner, student showcase, about section and contact form
- Admin login with dummy username and password
- Admin dashboard showing total students and departments count
- Add new students with name, department, image URL and description
- Delete student records
- Search students by name or department
- Filter by department dropdown
- Toggle between card view and table view
- All data is saved in browser localStorage

Technology:
- HTML5
- CSS3
- JavaScript (vanilla)

Files:
- index.html  -> main HTML page
- style.css   -> all the styling
- script.js   -> JavaScript logic
- README.txt  -> project info (this file)
